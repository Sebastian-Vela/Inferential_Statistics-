Teorema Central del Límite (TCL)

Este repositorio contiene un script en Python que demuestra de forma práctica y visual el **Teorema Central del Límite** utilizando simulaciones con distribuciones Binomial y Exponencial.

## ¿Qué hace este código?
1. **Simulaciones básicas:** Genera muestras de variables aleatorias de Bernoulli y Binomial.
2. **TCL con Distribución Binomial:** Simula múltiples muestras de una distribución binomial, calcula sus medias y genera un gráfico con Seaborn para mostrar cómo se aproximan a una campana de Gauss (distribución normal).
3. **TCL con Distribución Exponencial:** Realiza el mismo proceso pero partiendo de una distribución exponencial, comprobando que el teorema aplica incluso si la distribución original no es normal.
